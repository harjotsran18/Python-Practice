# Python Practice

A collection of introductory Python scripts covering fundamentals, data types, operators, exception handling, and basic conditional workflows.

## Contents

- `hello.py` - Introductory print script
- `yourname.py` - Basic input/output
- `datatype.py` - Exploration of Python data types
- `arithmetic.py` - Arithmetic operators
- `relational.py` - Relational/comparison operators
- `logical.py` - Logical operators
- `identity.py` - Identity operators (`is`, `is not`)
- `membership.py` - Membership operators (`in`, `not in`)
- `statemenst.py` - Conditional statements
- `vote.py` - Eligibility check example
- `age.py` - Age calculations and conditions
- `student.py` - Student record/details processing
- `exception.py` - Basic exception handling with try/except
- `exception2.py` - Multiple exception handling examples
